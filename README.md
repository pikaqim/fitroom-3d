# FitRoom 3D · 智能试衣间（Web 版）

选择衣物与人物，一键生成 3D 试穿效果；360° 旋转、缩放查看，保存多套穿搭并排对比。

在线体验：**GitHub Pages 部署后填写（见下方）**

## 功能

- **衣物素材**：上装 / 下装 / 连衣裙 / 鞋子 四类目，选中即可"上身"；支持上传衣物图片（自动提取主色，演示）
- **试穿人物**：三位预置模特（不同性别 / 肤色 / 体型），支持上传自定义照片、模拟现场拍摄
- **AI 试穿生成**：模拟五步生成流水线（正式版接入 IDM-VTON 类试穿模型）
- **3D 查看**：拖拽 360° 旋转、滚轮缩放、正面/侧面/背面预设视角、自动转台
- **穿搭管理**：保存到「我的试衣间」、双方案并排对比、一键恢复、localStorage 状态持久化

## 技术栈

- 原生 ES Modules + Three.js（本地 vendor，无构建步骤）
- WebGL 实时渲染：车削曲面人体建模 + 服装外壳网格 + 软阴影
- 纯静态站点，可部署到任意静态托管（GitHub Pages / Netlify / Vercel）

## 本地运行

```bash
cd fitroom-3d
python -m http.server 8080
# 或
npx serve .
```

浏览器打开 http://localhost:8080 （需通过 HTTP 访问，ES Module 不支持 file:// 直开）

## 目录结构

```
fitroom-3d/
├── index.html          # 页面骨架
├── css/style.css       # 全局样式
├── js/
│   ├── app.js          # 应用状态、UI 渲染、交互、持久化
│   ├── stage.js        # Three.js 引擎：人体建模、服装外壳、相机、快照

│   └── vendor/         # three.js、lucide 图标（本地化依赖）
└── tests/              # 验收测试报告
```

## 演示边界说明

- 「AI 生成」为前端模拟流水线：衣物状态会记录并展示，真实上身合成需后端接入图生图试穿模型（IDM-VTON / Kolors-VTON 等）
- 上传衣物仅提取主色示意；正式版为 AI 抠图 + 类目识别
- 上传的人物照片在演示中以 3D 人台形象呈现；正式版由模型保持人物一致性
